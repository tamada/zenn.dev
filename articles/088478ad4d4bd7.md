## 🗣️ 背景

プロジェクト開始時に `.gitignore` を作成するツールとして、[gitignore.io](https://www.toptal.com/developers/gitignore/) や [`simonwhitaker/gibo`](https://github.com/simonwhitaker/gibo) がある。
どちらも著名なツール/サービスであるので、使っている人も多いと想像する。
私も `gibo`を愛用していた。

しかし、`gibo`を使って行くうちに、以下のような機能的に物足りなくなってきた。

1. 今の `.gitignore` にどのようなエントリがあるのか、
2. `.gitignore` の先頭に幾つかのエントリを追加することがあるが、`gibo`で更新すると消えてしまう。
3. 個人的に作った boilerplate を使いたい。
4. いつも設定している内容をエイリアスとして扱いたい。
  - いつも `gibo dump macos linux windows` に続けて、プログラム言語やエディタなどを続けている。
  - さらに言えば、エディタは基本的に `jetbrains visualstudiocode` だし、プログラム言語は、goかRustなので、`go.mod`や`Cargo.toml`などのファイル名からわかる。

以前に、上記の 1, 2 を解決するようなツール [`tamada/gibo-wrapper`](https://github.com/tamada/gibo-wrapper)を作ったが、上記の 3, 4 の不満も大きくなってきた。
そこでついカッと頭に血が上り [`tamada/gixor`](https://github.com/tamada/gixor) というツールを作ってしまった。

https://github.com/tamada/gixor

## 🏃　Usage

基本的な使い方は `gibo` を踏襲している。

```sh
git ignore [OPTIONS] [ARGS...]
    or 
gixor [OPTIONS] <COMMAND>

Commands:
  alias       List the aliases
  dump        Dump the boilerplates
  entries     List the current entries in the .gitignore file
  list        List available boilerplates
  root        Show the root directory of the boilerplate
  search      Search the boilerplates from the query
  update      Update the gitignore boilerplate repositories (alias of `repository update`)
  repository  Manage the gitignore boilerplate repositories
  help        Print this message or the help of the given subcommand(s)

Options:
  -l, --log <LOG>             Specify the log level [default: warn] [possible values: trace, debug, info, warn, error]
  -c, --config <CONFIG_JSON>  Specify the configuration file
  -h, --help                  Print help
  -V, --version               Print version
```

- `gixor entries` が `.gitignore` にある内容の一覧を表示するコマンド。
  - ただし、`gibo` もしくは `gixor` で作成した `.gitignore` の内容しか見ません。
- `gixor dump` で最初に現れる boilerplate エントリの前の項目はそのまま出力されるようにしている。
  - ただし、そのために `gixor dump .... > .gitignore` はできません。
  - `gixor dump --replace ....` とすると `.gitignore` が置き換えられます。
  - `gixor dump --replace +macos` のように boilerplate 名の前に `+` をつけていると、`.gitignore` のエントリに `macos`が追加されます。すでに存在する場合は何もしません。
  - `gixor dump --replace -- -macos` のように boilerplate 名の前に `-` をつけていると、`.gitignore` のエントリから `macos`が削除されます。存在しない場合は何もしません。
    - `-macos` をオプションではなく引数として認識させるため、`--` が必要なのは面倒なので、`_` でも同様に動作します（`gixor dump --replace _macos`）。
- `gixor alias` でエイリアスの一覧が表示されます。`--edit` オプションで EDITOR 環境変数で設定されたエディタで編集できます。
